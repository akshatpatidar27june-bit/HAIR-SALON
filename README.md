# HAIR-SALON

Multi-outlet salon operations system.

## Architecture
- Next.js application → Vercel
- Backend/API + PostgreSQL → Render
- Source control → GitHub
- Custom domain → Hostinger DNS → Vercel

## Product
Owner-controlled multi-outlet salon sales and staff service tracking. Staff record only customer name, service, payment mode and amount. Owners and managers receive operational dashboards, outlet switching, reports, settlements and controls.

## Status
Foundation initialized. Application implementation follows in subsequent commits.
